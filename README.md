# Laboratorios de Python

Este repositorio contiene las actividades y ejercicios desarrollados durante los laboratorios de Python.

## Laboratorio 1: Primeros pasos con Python

En este laboratorio se trabajan variables, tipos de datos, operadores, entrada de información y la aplicación integradora Cotizador de compra.

## Objetivos

- Practicar los conceptos básicos de Python.
- Ejecutar programas desde la terminal.
- Realizar operaciones aritméticas.
- Crear un cotizador de compra en consola.

## Ejecución

Los programas se ejecutan desde la terminal utilizando Python 3.

Ejemplo:

```bash
python3 cotizador_compra.py
```

## Estado del proyecto

En desarrollo. El contenido se actualizará a medida que se completen los laboratorios.
